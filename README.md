# How to run on your computer

## Windows

1. Install [Node.js](https://nodejs.org) (Recommended: 18 or higher because this project is using native fetch module)
2. Open terminal in project directory (You can skip this if you use GUI)
3. Install dependencies and build

- Type `init.bat` in terminal or double click file explorer.

4. Execute the start script

- Type `run.bat` in terminal or double click in file explorer.

## Linux / MacOS

> [Warning]
>
> Linux/MacOS is unsupported/tested.

1. Install [Node.js](https://nodejs.org)@^20
2. Install dependency and build

- `npm i && npm run build`

3. Start bot

- `chmod +x ./run.sh` and `./run.sh`
